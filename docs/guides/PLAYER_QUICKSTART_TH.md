# เริ่มใช้ Shyne ใน 1 นาที

คู่มือนี้สำหรับ **ผู้เล่นที่ดาวน์โหลด Shyne Creator แล้วไม่รู้ว่าต้องทำอะไรต่อ** หากต้องการสร้างโมเดลของตัวเอง ให้ไปที่ [สร้าง Avatar แรก](CREATOR_QUICKSTART_TH.md)

## Shyne Creator คืออะไร

Shyne Creator เป็น runtime สำหรับเปิดใช้ Avatar, ท่าทาง และ Content Pack ภายใน Minecraft ตัวม็อดไม่ได้แถม Avatar หรือสกิลสำเร็จรูปมาให้ ดังนั้นหลังติดตั้งครั้งแรก การเห็นตัวละคร Minecraft แบบปกติถือว่าถูกต้อง

## 1. ตรวจว่าติดตั้งถูกไฟล์

- Fabric ใช้ไฟล์ชื่อ `shyne-creator-fabric-...jar` และต้องมี Fabric API
- NeoForge ใช้ไฟล์ชื่อ `shyne-creator-neoforge-...jar`
- เลือกเพียง Loader เดียวและใช้ Minecraft 26.3
- ไฟล์ Shyne Creator Kit ใช้สำหรับสร้าง Avatar และนำไปใส่ในโฟลเดอร์ `mods` ไม่ได้

เปิดเกมแล้วมองหาโลโก้ Shyne ในหน้าเมนูหลัก หรือเข้าโลกแล้วเปิด `Esc → อวตาร` หากพบเมนูนี้ แปลว่าตัวม็อดทำงานแล้ว

## 2. เปิดคลังอวตาร

เข้าโลก Minecraft แล้วใช้วิธีใดวิธีหนึ่ง:

- กด `G` แล้วเลือก `จัดการอวตาร` ในหน้าตัวควบคุม Shyne
- กด `Esc` แล้วเลือก `อวตาร`
- เปิดหน้า Settings ของ Shyne แล้วเลือก `จัดการอวตาร`

ปุ่มทั้งหมดเปลี่ยนได้จากหน้า Controls ของ Minecraft

## 3. เพิ่ม Avatar

### วิธีติดตั้งไฟล์ Avatar ที่มีอยู่

1. ในคลังอวตาร กด `เปิดโฟลเดอร์` ที่ด้านล่าง (จะเปิดโฟลเดอร์ `.minecraft/shyne-mods/avatars/`)
2. **รองรับไฟล์ `.zip` โดยตรง**: สามารถวางไฟล์ `my-avatar.zip` ลงในโฟลเดอร์ `shyne-mods/avatars/` ได้ทันทีโดยไม่ต้องแตกไฟล์! ระบบจะตรวจสอบและโหลดให้โดยอัตโนมัติ
3. หรือวางแบบโฟลเดอร์ปกติ `shyne-mods/avatars/<avatar-id>/` ที่มี `avatar.json` และ `model.bbmodel`
4. กลับเข้าเกมแล้วกด `สแกนไฟล์`

โครงสร้างที่ถูกต้อง:

```text
.minecraft/shyne-mods/avatars/
├─ my-avatar.zip           (แบบ ZIP วางได้โดยตรง)
└─ my-avatar/              (หรือแบบโฟลเดอร์)
   ├─ avatar.json
   └─ model.bbmodel
```

### วิธีเสริม: ค้นหาจาก Cloud

1. เปิดคลังอวตารแล้วกด `Cloud`
2. ยืนยันบัญชี Minecraft เมื่อระบบขอ
3. เปิดแท็บค้นหา Public แล้วเลือก Avatar
4. ตรวจสิทธิ์ที่ Avatar ขอ จากนั้นดาวน์โหลดและใช้งาน

Avatar Cloud เป็นระบบเสริมและปิดไว้ตั้งแต่แรก หากปุ่ม Cloud ปิดอยู่ ให้เปิดจาก `ตั้งค่า Shyne → คลาวด์`

## 4. เลือกใช้ Avatar

เมื่อ Avatar ปรากฏในรายการ ให้กด `เลือกใช้` หากไฟล์ถูกต้อง ตัวอย่างตัวละครด้านซ้ายจะเปลี่ยนและสถานะจะแสดงว่า Avatar พร้อมใช้

สำหรับ Avatar ที่ติดตั้งถูกต้อง ผู้เล่นไม่ต้องแก้ `avatar.json` หรือปรับค่าม็อดก่อนใช้งาน ท่าทางและการแสดงผลพื้นฐานใช้ค่าที่ผู้สร้าง Avatar เตรียมไว้ ส่วนการเปลี่ยนชุด ปุ่มพิเศษ และการตั้งค่าขั้นสูงค่อยปรับภายหลังได้

หากมีเครื่องหมาย `!` ให้กดเพื่ออ่านปัญหา หรือเลือก `เพิ่มเติม... → ตรวจไฟล์`

## 5. ใช้ท่าทางและคำสั่ง

- กด `G` เพื่อเปิดคำสั่งอวตาร เช่น ท่าทาง สีหน้า หรือการเปลี่ยนรูปแบบ
- เลื่อนหน้าในวงล้อเพื่อเปิดตัวควบคุม Shyne เช่น จัดการอวตาร ชุด และ Settings; เปิดได้แม้ยังไม่เลือก Avatar
- ตัวละคร 3D จะอยู่กลางวงล้อ และเปิดหรือปิดได้ใน `Settings → อวตาร → แสดง Avatar 3D ในวงล้อ`
- ปุ่ม `Z`, `X`, `C` และ `V` เป็นช่องความสามารถจาก Content Pack จึงอาจไม่ทำอะไรหากโลกหรือเซิร์ฟเวอร์ไม่ได้ติดตั้งแพ็กที่รองรับ

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีตรวจและแก้ |
| --- | --- |
| เข้าเกมแล้วไม่มีอะไรเปลี่ยน | กด `G` แล้วเลือก `จัดการอวตาร` เพื่อเพิ่ม Avatar ก่อน ตัวม็อดไม่แถม Avatar มาให้ |
| ไม่พบเมนู Shyne | ตรวจ Minecraft 26.3, Loader และไฟล์ JAR; Fabric ต้องมี Fabric API |
| คลังอวตารมีแต่ตัวละครพื้นฐาน | กดเปิดโฟลเดอร์เพื่อติดตั้ง Avatar แล้วกดสแกนไฟล์ |
| วาง Avatar แล้วไม่ขึ้น | ตรวจว่าแตก ZIP แล้ว และ `avatar.json` อยู่ในโฟลเดอร์ Avatar ชั้นแรก |
| Avatar ขึ้นเครื่องหมาย ! | เปิด `ตรวจไฟล์` เพื่อดูชื่อไฟล์หรือโครงสร้างที่ผิด |
| กด G แล้วไม่มีอะไรเกิดขึ้น | ตรวจว่าปุ่ม Action Wheel ยังตั้งเป็น `G` ใน Controls และไม่มีปุ่มอื่นใช้ซ้ำ |
| ปุ่มสกิล Z/X/C/V ใช้ไม่ได้ | ต้องมี Content Pack ที่รองรับ และ Multiplayer ต้องใช้ Shyne รุ่นตรงกันทั้ง Client และ Server |
