## 1. ความต้องการของระบบ

| รายการ | รายละเอียดที่รองรับ |
| :--- | :--- |
| **Minecraft** | เวอร์ชัน **26.3** |
| **Java** | Java **25** ขึ้นไป |
| **Mod Loaders** | **Fabric Loader** (0.19.3+) หรือ **NeoForge** (26.3.0.16-beta+) |
| **Dependencies เสริม** | Fabric API (จำเป็นสำหรับ Fabric) / Simple Voice Chat (ไม่บังคับ แต่แนะนำสำหรับการตรวจจับเสียงไมค์) |

> ⚠️ **ข้อควรระวัง:** ไฟล์ม็อดสำหรับ Fabric และ NeoForge เป็นคนละไฟล์กัน **ห้าม** ใส่ทั้งสองไฟล์ลงในโฟลเดอร์ `mods/` พร้อมกันเด็ดขาด

## 2. ขั้นตอนการติดตั้งม็อด (Fabric & NeoForge)

### สำหรับผู้ใช้ Fabric
1. ดาวน์โหลดและติดตั้ง **Fabric Loader 26.3**
2. ดาวน์โหลด **Fabric API** สำหรับ Minecraft 26.3
3. ดาวน์โหลดม็อด **`shyne-creator-fabric-2.18.0.jar`** จาก [CurseForge](https://www.curseforge.com/minecraft/mc-mods/shyne-creator)
4. นำทั้งสองไฟล์ไปใส่ในโฟลเดอร์:
   ```text
   .minecraft/mods/
   ```

### สำหรับผู้ใช้ NeoForge
1. ดาวน์โหลดและติดตั้งตัวติดตั้ง **NeoForge 26.3**
2. ดาวน์โหลดม็อด **`shyne-creator-neoforge-2.18.0.jar`** จาก [CurseForge](https://www.curseforge.com/minecraft/mc-mods/shyne-creator)
3. นำไฟล์ไปใส่ในโฟลเดอร์ `.minecraft/mods/`

## 3. การหาและติดตั้ง Avatar ตัวแรก

ใน Shyne Creator ตัวม็อดเป็น **ระบบแสดงผลและรันสคริปต์** จึงไม่มี Avatar ติดมาแต่แรก คุณสามารถเพิ่ม Avatar ได้อย่างง่ายดายด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

### วิธีที่ 1: วางไฟล์ ZIP โดยตรง (ง่ายที่สุด)
เมื่อคุณดาวน์โหลดไฟล์ Avatar ที่เป็น `.zip` มา (เช่น จากเพื่อนหรือเว็บไซต์):
1. เปิดโฟลเดอร์:
   ```text
   .minecraft/shyne-mods/avatars/
   ```
2. วางไฟล์ `.zip` ลงในโฟลเดอร์นี้ได้ทันที ตัวม็อดมีระบบ **Zip Auto-Extractor** ที่จะแตกไฟล์และแคชอย่างปลอดภัยโดยไม่ต้องแตกไฟล์เอง

### วิธีที่ 2: วางแบบโฟลเดอร์โปรเจกต์
หากเป็นโฟลเดอร์ Avatar ที่แตกไฟล์แล้ว โครงสร้างโฟลเดอร์ควรมีลักษณะดังนี้:
```text
.minecraft/shyne-mods/avatars/my_avatar/
├── avatar.json      (ไฟล์คอนฟิกหลัก)
├── model.bbmodel    (ไฟล์โมเดล 3D จาก Blockbench)
├── texture.png      (รูปภาพสกิน/พื้นผิว)
└── scripts/         (ไม่บังคับ - สคริปต์ Lua เสริม)
```

> 💡 **ฟีเจอร์ใหม่ Auto-Discovery:** หากคุณเคยใช้งานม็อด Figura มาก่อน คุณสามารถใส่ Avatar ไว้ในโฟลเดอร์เดิม `.minecraft/figura/avatars/` ตัวม็อด Shyne Creator จะสแกนพบและแสดงในคลังให้อัตโนมัติ!

## 4. การเปิดคลังและการใช้งานในเกม

1. เข้าเล่นในโลก Singleplayer หรือเซิร์ฟเวอร์ Multiplayer ใดก็ได้
2. กดปุ่มลัด **`G`** บนคีย์บอร์ด แล้วคลิก **"จัดการอวตาร"** (หรือกดปุ่ม `Esc` แล้วเลือกเมนู **"อวตาร"**)
3. **การเลื่อนดูคลัง:** ใช้ **ลูกกลิ้งเมาส์ (Mouse Wheel)** เลื่อนขึ้น-ลงได้อย่างลื่นไหล พร้อมแถบ Scrollbar เรืองแสง
4. หากเพิ่งเพิ่มไฟล์ใหม่เข้าไป ให้กดปุ่ม **"สแกนไฟล์"**
5. คลิกที่รูป Avatar ที่ต้องการ แล้วกดปุ่ม **"เลือกใช้"** (Use Avatar)
6. ตัวละครของคุณจะเปลี่ยนเป็นโมเดล Avatar 3D ใหม่ทันที!

## 5. การตั้งค่าระบบเสียงพูดไมค์ให้ปากขยับ

Shyne Creator มีระบบ **Automatic Mouth Speech Tracking**:
* **เมื่อเปิดไมโครโฟนพูด:** หากคุณติดตั้งม็อด Simple Voice Chat หรือเปิดระบบไมค์ไว้ เมื่อมีเสียงพูด ชิ้นส่วนปาก (`mouth_open`) จะเปิด-ปิดขยับตามจังหวะเสียงพูดของคุณทันที
* **เมื่อส่งข้อความในแชท:** เมื่อคุณพิมพ์ข้อความและกดส่ง ปากของตัวละครจะขยับเสมือนกำลังพูดข้อความนั้นออกไป 1-2 วินาที
* **การปรับระดับความไว:** สามารถเปิดเมนู `Esc -> อวตาร -> ตั้งค่า` เพื่อปรับค่า Threshold ระดับความดังเสียงพูดไมค์ที่ต้องการให้ปากเริ่มขยับได้

## 6. การใช้งานวงล้อคำสั่ง (Action Wheel ปุ่ม G)

เมื่อ Avatar มีการเขียนคำสั่งหรือท่าทางเตรียมไว้:
1. กดปุ่ม **`G`** ค้างไว้เพื่อเปิดวงล้อคำสั่ง **Action Wheel** 8 ทิศทาง
2. เลื่อนเมาส์ไปยังทิศทางคำสั่งที่ต้องการ เช่น:
   * 🎭 **เปลี่ยนสีหน้า:** ดีใจ, โกรธ, ร้องไห้
   * 💃 **ท่าทาง (Emotes):** โบกมือ, เต้น, นั่งสมาธิ
   * 👒 **สลับชุด/อุปกรณ์:** ถอดหมวก, ถอดแว่น, เปลี่ยนอาวุธ
3. ปล่อยปุ่ม หรือคลิกซ้ายเพื่อสั่งใช้งาน คำสั่งเหล่านี้จะถูกซิงก์ให้เพื่อนๆ ทุกคนในเซิร์ฟเวอร์เห็นพร้อมกันแบบเรียลไทม์!
