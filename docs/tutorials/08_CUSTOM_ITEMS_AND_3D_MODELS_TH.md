# 🗡️ บทเรียนที่ 8: สร้างไอเท็มและอาวุธ 3D ด้วย Blockbench (Custom 3D Items)

ใน **Shyne Creator** ผู้สร้างสามารถสร้าง **ไอเท็มและอาวุธแบบโมเดล 3D** (เช่น คทาเวทมนตร์, ดาบคริสตัล, โล่พลังงาน, หรือเครื่องราง) แล้วนำมาถือในมือได้โดยตรง ผ่านระบบ **Native 3D Item Presentation** 

ระบบนี้เป็นเอกลักษณ์เฉพาะของ Shyne Creator:
* 🌟 **ไม่ต้องทำ Resource Pack ซับซ้อน:** ใส่ไฟล์ `.bbmodel` ได้โดยตรง
* 🌟 **แสดงผล 3D ทุกมุมมอง:** ทั้งในมุมมองบุคคลที่หนึ่ง (First-Person), บุคคลที่สาม (Third-Person), ในช่องกระเป๋า (GUI Inventory), ไอเท็มดรอปบนพื้น (Ground), และกรอบรูป (Item Frame)
* 🌟 **เชื่อมกับระบบพลัง:** สามารถคลิกขวาเพื่อยิงสกิลเวทมนตร์ (Combat Skills) ได้ทันที

## 1. โครงสร้างไฟล์ของไอเท็ม 3D

เพิ่มโฟลเดอร์ `items/` และ `bbmodels/` ในแพ็กของคุณ (`.minecraft/shyne-mods/my_power_pack/`):

```text
my_power_pack/
├── mod.json
├── shyne-package.json
├── main.lua
├── assets/
│   └── icons/
│       └── arcane_focus.png     (ไอคอน 2D สำหรับแสดงใน UI แคตตาล็อก)
├── bbmodels/
│   ├── arcane_focus.bbmodel     (ไฟล์โมเดล 3D จาก Blockbench)
│   └── arcane_focus.png         (Texture สกินของโมเดล 3D)
├── items/
│   └── arcane_focus.json        (ไฟล์คอนฟิกคุณสมบัติของไอเท็ม)
└── skills/
    └── arc_bolt.json            (สกิลพลังที่ผูกกับไอเท็ม)
```

---

## 2. การสร้างโมเดลไอเท็มใน Blockbench

1. เปิดโปรแกรม **Blockbench**
2. เลือก **File > New > Generic Model** (หรือ Shyne / Modded Entity)
3. ตั้งชื่อโมเดลเป็น `arcane_focus`
4. **การจัดวางตำแหน่งโมเดลในมือ:**
   - วางจุดศูนย์กลางของด้ามจับให้อยู่ที่พิกัด `(0, 0, 0)`
   - ให้ตัวโมเดลชี้ขึ้นไปตามแกน **Y** (ขึ้นด้านบน) และหันหน้าไปทางแกน **Z**
   - ขนาดที่แนะนำ: ความยาวประมาณ 16–24 Units (พอเหมาะกับมือของตัวละคร Minecraft)
5. วาด Texture สวยงาม และบันทึกไฟล์เป็น:
   * `arcane_focus.bbmodel`
   * `arcane_focus.png` (Texture)
6. คัดลอกทั้งสองไฟล์ไปไว้ในโฟลเดอร์:
   ```text
   my_power_pack/bbmodels/
   ```

## 3. การเขียนไฟล์คอนฟิกไอเท็ม (Item Definition JSON)

สร้างไฟล์ `items/arcane_focus.json`:

```json
{
  "item_id": "my_power_pack.arcane_focus",
  "display_name": "Arcane Focus",
  "description": [
    "คทาคริสตัลโบราณที่กักเก็บกระแสไฟฟ้า",
    "§eคลิกขวา:§7 ปล่อยลูกศร Arc Bolt (ใช้มานา 10)"
  ],
  "icon": "arcane_focus",
  "rarity": "rare",
  "max_stack": 1,
  "glint": true,
  "use_skill": "my_power_pack.arc_bolt",
  "cooldown_ticks": 15,
  "consume_on_use": false,
  "presentation": {
    "model_id": "my_power_pack:arcane_focus",
    "scale": 0.75,
    "offset_y": 0.05,
    "rotation_y": 18,
    "replace_vanilla": true
  }
}
```

## 4. การปรับแต่งการถือในมือ (Presentation Settings)

บล็อก `presentation` คือหัวใจสำคัญที่บอกให้เอนจินของ Shyne เรนเดอร์โมเดล 3D:

| ตัวเลือกใน `presentation` | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `model_id` | String | *จำเป็น* | ชื่อ `<pack_id>:<ชื่อไฟล์_bbmodel>` เช่น `my_power_pack:arcane_focus` |
| `scale` | Float | `1.0` | อัตราส่วนขยายโมเดล (แนะนำ `0.70` – `0.85` สำหรับอาวุธถือมือ) |
| `offset_x` / `y` / `z` | Float | `0.0` | ระยะขยับตำแหน่งเพื่อให้พอดีกับกำปั้นของตัวละคร |
| `rotation_x` / `y` / `z` | Float | `0.0` | องศาการเอียงของอาวุธเวลาถือ |
| `replace_vanilla` | Boolean | `true` | ซ่อนไอเท็มวานิลลาเดิม และแสดงเฉพาะโมเดล 3D แบบคลีน |

> 🛡️ **ความปลอดภัยในการเรนเดอร์ (Graceful Fallback):** หากผู้เล่นคนอื่นในเซิร์ฟเวอร์ยังดาวน์โหลดโมเดล 3D ไม่เสร็จ ตัวเกมจะแสดงเป็นไอคอน 2D ปกติโดยอัตโนมัติ ไอเท็มจะไม่ล่องหน และไม่ทำให้เกมแครช

## 5. การเชื่อมโยงไอเท็มเข้ากับสกิลพลัง (`use_skill`)

เมื่อคุณระบุฟิลด์:
```json
"use_skill": "my_power_pack.arc_bolt",
"cooldown_ticks": 15,
"consume_on_use": false
```
* **คลิกขวาในมือ:** ตัวเกมจะส่งคำสั่งไปยัง Server เพื่อตรวจสอบเงื่อนไขมานาและคูลดาวน์โดยอัตโนมัติ
* **`consume_on_use: false`:** ไอเท็มจะไม่หายไปเมื่อใช้ (เหมาะสำหรับอาวุธ/คทาเวทมนตร์) หากตั้งเป็น `true` จะลดจำนวนไอเท็มลง 1 ชิ้น เหมาะสำหรับยาเวทมนตร์หรือม้วนคัมภีร์

## 6. การเขียน Lua Hook เมื่อกดใช้ไอเท็ม (`on_item_use`)

ในไฟล์ `main.lua` ของแพ็ก คุณสามารถใส่ Hook ดักจับเหตุการณ์เมื่อผู้เล่นกดใช้ไอเท็มสำเร็จได้:

```lua
-- main.lua

function on_item_use(ctx)
  if ctx.item_id == "my_power_pack.arcane_focus" then
    -- เล่นเสียงกระดิ่งคริสตัลดังก้อง
    fx.sound("minecraft:block.amethyst_block.hit", ctx, "players")
    
    -- ข้อความแจ้งเตือนผู้เล่น
    player.say("✨ คุณรู้สึกได้ถึงพลังงาน Arcane ที่ไหลผ่านมือ!", ctx)
  end
end
```

### ข้อมูลที่ส่งมาใน `ctx`:
* `ctx.player`: ตัวละครผู้เล่นที่ใช้ไอเท็ม
* `ctx.item_id`: รหัสไอเท็มที่ถูกใช้
* `ctx.skill_id`: รหัสสกิลที่ผูกไว้
* `ctx.hand`: มือที่ถือไอเท็ม (`MAIN_HAND` หรือ `OFF_HAND`)

## 7. การเสกไอเท็มและทดสอบในเกม

1. เข้าเล่นเกมในโลก Minecraft
2. เสกไอเท็มมาไว้ในมือด้วยคำสั่ง:
   ```text
   /shyne item give @p my_power_pack.arcane_focus
   ```
3. **ตรวจสอบการแสดงผล:**
   * **มุมมองบุคคลที่สาม (กดปุ่ม F5):** จะเห็นตัวละครถือคทาคริสตัล 3D สวยงาม
   * **ในกระเป๋า (กดปุ่ม E):** ไอเท็มจะโชว์เป็นโมเดล 3D พร้อมกรอบ Tooltip สีทอง/ม่วง (ตามระดับ Rarity) และมีแสงสะท้อน Glint
   * **คลิกขวา:** ลูกกระสุน Arc Bolt จะถูกยิงออกไปทันที พร้อมหักหลอดมานาและเริ่มนับคูลดาวน์!
