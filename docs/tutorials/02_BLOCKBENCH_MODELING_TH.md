## 1. เตรียมโปรแกรมและติดตั้ง Shyne Plugin

1. ดาวน์โหลดโปรแกรม [Blockbench](https://www.blockbench.net/) (เวอร์ชัน 4.9+ ขึ้นไป)
2. ติดตั้งปลั๊กอิน Shyne:
   * ใน Blockbench ไปที่เมนู `File` → `Plugins` → แท็บ `Load from File`
   * เลือกไฟล์ `tools/blockbench/shyne_standard_2.js` ในโฟลเดอร์ม็อด
   * จะปรากฏเมนู **Shyne Standard** และปุ่มตรวจสอบความเข้ากันได้ทันที

## 2. การตั้งค่าโครงสร้างกระดูกให้ตรงกับ Minecraft Vanilla

เพื่อให้โมเดลของคุณขยับตามร่างกายของผู้เล่นในเกม โครงกระดูกหลักต้องมีชื่อตรงกับมาตรฐาน Vanilla:

```text
root (Group หลัก - ไม่บังคับ)
├── Head        (หัว - หมุนตามมุมมองสายตาผู้เล่น)
├── Body        (ลำตัว - หมุนและเอียงตามท่าทาง)
├── LeftArm     (แขนซ้าย)
├── RightArm    (แขนขวา - ใช้แสดงในมุมมองบุคคลที่หนึ่งด้วย)
├── LeftLeg     (ขาซ้าย)
└── RightLeg    (ขาขวา)
```

> ⚠️ **ข้อสำคัญ:** ตัวพิมพ์เล็ก-ใหญ่ (Case-sensitivity) มีความสำคัญ ควรตั้งชื่อตัวแรกด้วยตัวพิมพ์ใหญ่ เช่น `Head`, `Body` เป็นต้น

## 3. การสร้างชิ้นส่วนต่อพ่วง (หู หาง ปีก ปาก) และ Pivot Points

หากต้องการเพิ่มชิ้นส่วนสัตว์หูหาง หรือเอฟเฟกต์ ให้สร้างเป็นกรุ๊ปย่อย (Child Group) ใต้กระดูกหลัก:

### กฎการจัดลำดับชั้น (Hierarchy):
* **หู (Ears) & หมวก (Hat):** ใส่เป็นกรุ๊ปย่อยข้างในกรุ๊ป `Head`
  ```text
  Head
  ├── ear_left
  └── ear_right
  ```
* **ปาก (Mouth):** สำหรับระบบ Lip-sync ให้ใส่กรุ๊ปย่อยชื่อ `mouth_open` หรือ `mouth` ไว้ใต้ `Head`
* **หาง (Tail):** ให้ใส่กรุ๊ปย่อยข้างในกรุ๊ป `Body`
  ```text
  Body
  └── tail_root
      └── tail_mid
          └── tail_tip
  ```

### การตั้งจุดหมุน (Pivot Points):
* **หู:** ต้องตั้ง Pivot Point อยู่ที่ฐานโคนหูติดกับกะโหลกศีรษะ เพื่อให้เวลาหูกระดิก จะหมุนรอบฐานหู ไม่ลอยกลางอากาศ
* **หาง:** ต้องตั้ง Pivot Point อยู่ที่โคนหางบริเวณก้น เพื่อให้เวลาส่ายหาง หางจะแนบสนิทกับสะโพกของผู้เล่นเสมอ

## 4. การทำ Texture และ Emissive Glowing Texture

### การใส่ Texture ทั่วไป:
1. สร้าง Texture ความละเอียดขนาดมาตรฐาน เช่น `64x64` หรือ `128x128` พิกเซล
2. ทำ UV Mapping ให้เหลี่ยมกล่องต่างๆ รับสีจาก Texture ได้ถูกต้อง

### การทำดวงตาเรืองแสงในที่มืด (Emissive Texture):
1. วาด Texture หลักปกติ บันทึกเป็น `texture.png`
2. สร้าง Texture อีกรูปหนึ่ง ตั้งชื่อว่า `texture_e.png` (หรือต่อท้ายด้วย `_e`)
3. ในรูป `texture_e.png` ให้ลบทุกส่วนออกเป็นโปร่งใสทั้งหมด **ยกเว้นบริเวณดวงตาหรือลวดลายเวทมนตร์**
4. Shyne Creator จะนำเลเยอร์ `_e` นี้ไปเรนเดอร์ด้วย Fullbright Shader ทำให้ดวงตาสว่างเรืองแสงแม้อยู่ในถ้ำมืดสนิท!

## 5. การสร้าง Animation และการตั้งชื่อ State Machine

ใน Blockbench สลับไปที่แท็บ **Animate** (มุมขวาบน)
เพื่อให้อนิเมชันเล่นโดยอัตโนมัติ (Zero-Lua) ให้ตั้งชื่ออนิเมชันตามชื่อมาตรฐานต่อไปนี้:

| ชื่อแอนิเมชัน | สภาวะที่เกมจะเล่นอัตโนมัติ |
| :--- | :--- |
| `idle` | เมื่อผู้เล่นยืนอยู่นิ่งๆ |
| `walk` | เมื่อผู้เล่นกำลังเดิน |
| `run` หรือ `sprint` | เมื่อผู้เล่นกำลังวิ่งเร็ว |
| `sneak` หรือ `crouch` | เมื่อผู้เล่นย่อตัว / หมอบ |
| `jump` | เมื่อผู้เล่นกระโดดลอยตัว |
| `fall` | เมื่อผู้เล่นตกจากที่สูง |
| `swim` | เมื่อว่ายน้ำในน้ำ |
| `fly` หรือ `elytra` | เมื่อบินด้วยปีก Elytra หรือโหมด Creative |
| `sit` | เมื่อนั่งบนเรือ รถม้า หรือเก้าอี้ |
| `blink` | แอนิเมชันกะพริบตา (สุ่มเล่นทุกๆ 3-5 วินาที) |
| `talk` หรือ `speak` | แอนิเมชันขยับปากเมื่อพูดไมค์หรือพิมพ์แชท |

> 💡 **Loop Mode:** สำหรับท่า `idle`, `walk`, `run` ให้ตั้ง Loop Mode เป็น **Loop** ในพาเนลด้านซ้ายของ Blockbench

## 6. การส่งออก (Export) เข้าสู่เกม

1. บันทึกไฟล์โมเดลเป็น `.bbmodel` (เช่น `model.bbmodel`)
2. นำไฟล์ `model.bbmodel` และไฟล์ Texture ทั้งหมดไปใส่ในโฟลเดอร์ Avatar ของคุณ
3. ในบทเรียนถัดไป เราจะมาดูการสร้างไฟล์ `avatar.json` เพื่อเชื่อมต่อโมเดลนี้เข้ากับเกมครับ!
