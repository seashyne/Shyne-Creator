# Modular Signature Weapon & Flight Avatar (ภาษาไทย)

ตัวอย่าง Avatar ฉบับสมบูรณ์สำหรับสาธิต:
1. **การเขียนสคริปต์แบบแบ่งโมดูล (Modular Architecture with `require`)**
2. **ระบบอาวุธประจำตัว 3D (Signature Weapon)** ที่สลับระหว่างสะพายหลัง (Sheath) กับถือในมือ (Hand) พร้อมท่าฟันและคลื่นพลังดาบ
3. **ระบบการบิน, กระโดดสูง และลอยตัว (Flight, Super Jump, Anti-Gravity Hover)** ผ่าน `player:setVelocity`
4. **การตรวจจับความเร็วแบบเรียลไทม์ (Speed Metrics in m/s)**
5. **การตรวจจับการตายและการเกิดใหม่ (Death & Respawn Detection)**
6. **เครื่องมือดีบัค (Debug Tools)** เติมมานาทันที / เปิดโหมดอมตะ
7. **รองรับการบีบอัดเป็น `.zip`** นำไฟล์ `.zip` ไปวางในโฟลเดอร์ avatars ได้โดยตรง!
